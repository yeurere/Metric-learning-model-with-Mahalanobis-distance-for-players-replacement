# Metric-learning-model-with-Mahalanobis-distance-for-players-replacement
This repository contains code for identifying similar players using metrics such as Mahalanobis distance, Euclidean distance, and cosine similarity. Team IDs were obtained from the link https://kffleague.kz/ru/team/51, while the JSON files containing player IDs were extracted from the team page's source code. All statistics are current as of November 2026. "2022-2023 Football Player Stats.csv" outdated to our work.
